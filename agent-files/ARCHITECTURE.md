# Architecture

This file is the authoritative record of finalized architectural decisions for Daedalus Marketplace.

## Current State

The repository currently contains the project README and licensing/repository metadata. The marketplace is a planned web platform for discovering, uploading, sharing, and downloading local AI capabilities.

No production marketplace architecture has been finalized yet.

## Relationship to Daedalus

Daedalus Marketplace is the ecosystem/distribution project associated with Daedalus. Do not assume that planned marketplace behavior is already implemented in this repository.

## Authority

Finalized decisions belong here. Temporary plans, discoveries, and open questions belong in `agent-files/Agents_Context.md`.

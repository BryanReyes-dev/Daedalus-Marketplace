# Agent Instructions — Daedalus Marketplace

Daedalus Marketplace is the planned web platform and marketplace for discovering, uploading, sharing, and downloading local AI capabilities such as agent skills, tools, workflows, and models.

## Before Working

1. Read `agent-files/Agents_Context.md` for current working state.
2. Read `agent-files/ARCHITECTURE.md` for finalized decisions.
3. Inspect the current repository before assuming an application implementation exists.
4. Treat the marketplace concepts described in the README as product direction unless the source confirms implementation.

## Documentation Authority

- `ARCHITECTURE.md` is authoritative for finalized architecture.
- `Agents_Context.md` is temporary working context.
- Do not silently promote product ideas or proposals into architecture.

## Implementation Rules

Keep this repository aligned with Daedalus's broader ecosystem without coupling implementation assumptions to the Daedalus runtime repository. Preserve existing behavior and avoid unrelated changes.

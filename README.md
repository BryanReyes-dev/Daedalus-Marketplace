# Daedalus-Marketplace

The web platform and marketplace for Daedalus, built for discovering, uploading, sharing, and downloading local AI capabilities. Browse and distribute agent skills, tools, workflows, and models that can be installed and run directly on your own machine, giving users a way to build, extend, and share their local AI environments.

## Agent Files

The `agent-files/` directory contains documentation for AI coding agents and is separate from this human-facing README and the application source. `AGENTS.md` contains agent instructions, `ARCHITECTURE.md` records finalized architecture, `Agents_Context.md` stores short-term working context, and `CLAUDE.md` provides the Claude entry point.
